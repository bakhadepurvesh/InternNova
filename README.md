Welcome to my repository for **InternNova Internship**! This section documents my progress, learning milestones, and practical assignments completed during **Week 1**, focusing on **Core Java Fundamentals and Procedural Programming**.

## 🚀 Week 1 Overview
The objective of Week 1 was to master the fundamentals of Java syntax, data handling, and control flow structures, building a solid foundation for problem-solving.

### Key Topics Covered:
* **Java Basics:** Structure of a Java program, main method, compilation, and execution.
* **Data Types & Variables:** Primitive types (int, double, char, boolean) and type casting.
* **Operators:** Arithmetic, relational, logical, and assignment operators.
* **Control Flow Statements:** 
  * Conditional statements (`if`, `if-else`, `nested if`, and `switch-case`)
  * Iterative statements / Loops (`for`, `while`, and `do-while`)
  * Jump statements (`break`, `continue`)
* **Arrays:** Single-dimensional and multi-dimensional arrays, along with basic array traversal.
